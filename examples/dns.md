The Domain Name System (DNS) associates names with records.

<quiz>
**What is the role of DNS?**

* [ ] Assign IP addresses.
* [x] Resolve domain names.
* [ ] Encrypt communications.

DNS resolves **domain names** into IP addresses.
</quiz>

A DNS server can return different types of records.

<quiz>
Which records return an *IP address* for a hostname?

* [x] An `A` record.
* [ ] An `MX` record.
* [x] An `AAAA` record.

The answer depends on the address family:

- `A` returns an IPv4 address.
- `AAAA` returns an IPv6 address.
</quiz>
